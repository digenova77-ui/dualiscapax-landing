Leftover

Every choice leaves something behind.

You eat pizza. Three slices stay in the box. Those slices still take fridge space. If you forget them, they cost more than they gave. That leftover is real even when nobody writes it down.

A bill does the same thing. A chat does the same thing. A machine that runs all night does the same thing. DualisCapax writes the leftover so you can see it before you lock a door.

Fingerprint

Crypto means a fingerprint you can test.

Take a sentence. Run it through a hasher. You get a long code. Change one letter. The code changes. That code is a fingerprint. Nobody has to trust a speech. They can run the same hasher and see if the print matches.

Coins sit on top of fingerprints. DualisCapax works on the fingerprint layer first: hashes, signatures, books you can audit. Markets come later.

Invert

If you cannot run the number backward, the number is a story.

Stories are allowed. Stories do not issue a bill. When someone says this saved you forty, you should be able to walk from forty back to the hours, the watts, the pages, or the waste. If you cannot, nothing is owed.
