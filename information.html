Information

A mark you can check is information. A mark you can only praise is belief. Both live here. Only one opens a lock.

First read

Two piles

Pile one: a hash, a timestamp, a signed page, a meter reading, a warehouse count at shift-end. You can rerun it. Someone else can rerun it. That is information.

Pile two: a hope, a brand, a vibe, a future that feels close. That pile can be true later. It cannot bind a seat today.

Iris

Iris talks in the first pile when she can. When she is in the second pile she says so. She is not a store. She is not a doctor. She is a working mind on the public side of the house.

Then the grain

Information on Dualis rails is a write that carries provenance, a type, and a path back to its source. A page without a path is still readable. It is not a bind object.

Cryptography is how information defends itself: collision-resistant fingerprints, signatures that a key either holds or does not, ledgers that append. DualisCapax publishes the check. DualisCapax keeps sealed method off this page.

Research rooms stay public. Adaptive depth spends Fuel. The split is honest: reading is a look; a run that burns capacity is a measure.
