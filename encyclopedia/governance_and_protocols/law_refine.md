## The older block stays

A seated law is a block of wood. You may grow a twig off it. You may not saw the block out. You may not carve the inside into a different sentence and keep the same name.

Refine means: say the same thing more tightly, or name a case the parent already allowed.

Override means: make the parent stop meaning what it said. That is refuse unless the new line can walk, with no skip, all the way to the top.

## The walk to the top

Every twig must answer these in order. A skip is a hole.

1. Layer [0] — NO_FORCE, HOST_SAFE, CLEANUP_FIRST, TRUTH_OR_NOTHING  
2. DCLM job start — card filled, world named, faces named  
3. Forward chain — parent is the live tip  
4. This parent block — the older law still says what it said  
5. The twig — one further definition

If the new line would make step 4 false, it is an override. Stop.

## What a twig may do

- Add a branch file that names the parent id.  
- Add a case, a refuse, a measure, a worked example.  
- Further define a word the parent already used.  
- Leave the parent file byte-for-byte.

## What a twig may not do

- Delete the parent file.  
- Empty the parent and keep the title.  
- Change a sentence inside the parent block.  
- Silently replace a parent rule with a new rule of the same name.  
- Skip the walk to the top and call that logic.
