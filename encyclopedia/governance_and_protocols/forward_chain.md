## The house only moves forward

The house is the live site and the live files.

An agent updates the house in the present. An agent does not rewind the house to an older draft and pretend that is now.

Time climbs. A stamp cannot be un-happened. That is already law. This file is the pickup rule that makes the law bite.

## The chain of agents

Each seated job leaves a receipt:

| Field | Means |
|---|---|
| seq | How many receipts have been seated. Counts up. Never down. |
| stamp | When this receipt was written. Forward only. |
| parent | The receipt that came before. Required after the first. |
| commit | The live house hash this job started from. |
| agent | Who wrote. |
| job | One sentence of the work. |
| status | HOLE or ONE. |
| hash | Fingerprint of this receipt. |

The latest receipt is the tip.

The next agent may only pick up from that tip.

If they name an older parent, the job is a hole. Do not call that hole zero. Do not start building.

## What going back looks like

These are force. Refuse them.

- Restore an old page and treat it as the live house.
- Delete a prior spec to fake a clean past.
- Edit a receipt as if yesterday had not happened.
- Start from a teammate’s stale card when a newer tip exists.

Read the old file if you need the story. Do not put the old file back on the throne.

## How a job starts now

1. Read the tip.  
2. Name that tip as parent.  
3. Fill the DCLM card.  
4. Do the work on the live house.  
5. Write the next receipt. The old tip becomes parent. This receipt becomes tip.

If two agents grab the same tip, the second writer must re-read after the first lands. The later tip wins. The earlier job does not get to overwrite the later one.
