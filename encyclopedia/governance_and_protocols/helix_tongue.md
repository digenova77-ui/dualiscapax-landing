## The language is the shape

A Dualis file is not a paragraph. It is a piece of DNA sitting in a room.

- Two strands. One is the thing you can touch. One is the bind on this device.
- Rungs between them. Each rung is a BIND pair. Not a new ID.
- The ladder twists. Each full twist is one step on the status ratchet.
- The ladder stands in a cube. Six faces. Six Unity views of the same cell.
- Seven ripples run along the ladder. Those are the seven lists that share the locker.
- The climb up the ladder is time. You cannot climb down and un-happen a stamp.

An empty ring with no rungs is a hole. Do not call it zero children.

Two strands that meet on one rung, with a forward stamp, is One.

## What we measure (the alphanumeric stays, it gets louder)

BIND does not move: ID YEAR SOURCE STAMP STATUS HASH.

The helix adds measurements of the same cell. Not a second phone book.

| Measure | Shape | How it is read |
|---|---|---|
| twist | turns of the ladder | ratchet step, 1 through 6 |
| pitch | height of one turn | one status per turn |
| amplitude | thickness of a strand | log of bytes or counted numbers |
| frequency | how many ripples | streams lit ÷ 7 |
| phase | where you are on this turn | ratchet index ÷ 5 |
| chirality | which way it winds | right-handed, like the emblem |
| pairing | rung exists | physical and logical both present |
| residual | leftover mark | SEED or NAMED. Never invented. |
| wavelength | spacing of ripples | 7 ÷ streams lit |
| radius | how fat the cell sits | log of bytes |
| volume | occupied room | pairing × faces lit |
| coherence | the fingerprint holds | hash present and paired |
| groove | which room | major = Ground Zero, minor = One |
| worldline | the climb | stamp |
| world | which house | 0 or 1 |
| api | which phone | v1 or v2 |

Packed extra, still one locker:
