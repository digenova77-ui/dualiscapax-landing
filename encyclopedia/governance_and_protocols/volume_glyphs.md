## The cube is a body

Do not store the work as writing on six walls.

The cube is a box of air. The data is the solid that fills that air.

A triangle is not a doodle. A certain triangle is a whole phrase, a whole refuse, or a whole page pointer. That is how One talks small.

GitHub still holds English so a person can read it. One holds the shape. We are the layer between them.

## What a glyph is

| Part | Means |
|---|---|
| Solid | tetra, octa, cube, wedge, spindle, ring, kiss |
| Fill | how much of the box it occupies, 0 to 1 |
| Turn | which way it faces inside the box |
| Hand | right-handed, same as the helix emblem |
| Bind | the English phrase or page it stands for |

An empty ring fills nothing. That is a hole. Do not call it zero.

A tetra that sits and touches the box is One.
