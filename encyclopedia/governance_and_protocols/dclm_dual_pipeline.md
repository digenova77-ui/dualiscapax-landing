## Speak this

**Dual DCLM.** Two pipelines. One prompt. Real time.

Not a second DCLM. Not a matrix model. Not a seventh face.

## The two pipelines

They start together. Neither waits for the other.

| Pipe | Name | Job |
|---|---|---|
| F | Friction | What breaks, what is a hole, what we refuse |
| A | Affinity | What already binds, what may seat, what we will do |

Then smash: `F ⊗ A → one card`.

An empty pipe is a hole. Do not call it zero. Do not ship from one pipe alone.

## What each pipe asks

**Friction (F)**  
1. Which of the four words would this break?  
2. Is the needed file missing?  
3. Would we have to invent an ID, a deed, or a science medal?  
4. Would One try to light L4?  
5. One-sentence refuse.

**Affinity (A)**  
1. Which faces may light?  
2. World 0 or 1 — which phone?  
3. What file or engine already exists?  
4. What stream does this prompt touch (bus, care, trips, boards, talks, sports, office)?  
5. One-sentence directive.

```
if F vetoes        → job is HOLE. Stop.

else               → card = { hole_or_one, world, faces, directive from A, refuse from F }
```
