## What the matrix is, in plain words

Think of a locker wall at a school.

- Each locker is one **cell**.
- The locker number is the **identifier**.
- What is inside the locker can be many kinds of notes at once (the bus list, the after-school list, the field-trip list). That is **parallel**.
- The date stamped on the door is the order things happened. That is **serial**.
- An empty locker is not "zero kids." It is a **hole**. We do not pretend a number exists when the locker is empty.

The same locker holds both:

1. **Physical plane** — the file, the tap, the room, the byte size.
2. **Logical plane** — the bind on this device, the layer, the gate.

A change counts only when both planes agree. If only one side shows up, the cell refuses. That is the merger from Zero to One.

## Identifiers already in use (do not mint a second set)

BIND intake already names:

- ID
- YEAR
- SOURCE
- STAMP
- STATUS
- HASH

The cell adds five axes that sit in the same record, not a new catalog:

- Entity (who or what)
- Time (when)
- Place (where)
- Gate (which door: L2 playground, L3 pass, and so on)
- Attestation (the device bind)

Seven lists can ride in that one cell at the same time:

1. Bus and rides
2. Before and after care
3. Trips and sign-offs
4. Public boards
5. Private talks
6. Sports and clubs
7. Office desk

## Zero to One

- **Zero** is an unseated cell. No file. No bind. Call it a hole, not a count of zero.
- **One** is the first seated cell: a real file or link on this device, and a real device bind, packed into one record.
- L2 can seat One. L2 cannot promote that cell into ownership, a live founder plaque, or a scientific claim.
