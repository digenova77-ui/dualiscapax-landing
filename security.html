How money and identity stay gated

The internet sees a serial. Stripe hears a signed post. Dualis does not keep cards. This page is the rule, not a secret.

Public plate

16-digit serial only. Hatch stays on the desk. No health number. No licence number. No passphrase.

Stripe path

Browser → Payment Link → Stripe → signed POST → fulfill worker.

https://dualiscapax-stripe-fulfill-v2.digenova77.workers.dev/

Events: checkout.session.completed · checkout.session.async_payment_succeeded

GitHub Pages does not receive the post and does not hold the webhook secret.

Signature

HMAC-SHA256 of t + "." + raw body. Five-minute window. Reject one way if anything fails.

Compare is constant-time: XOR every byte, then test the accumulator. No early return on the first mismatch.

Side channels we refuse

Different error text for bad header vs bad HMAC. Parse-then-stringify before hash. Secrets in git. Card photos in chat. Treating localStorage “I paid” as money. KV off means replay is only blocked by the time window — bind FULFILL_KV.

Passes

Look is free. A grind pass spends only if the work can finish. No published expiry date. $350 pack has no button.
