# Production line — software agencies

Ford: one station, one job, chassis only moves forward.
Dualis: one agency kind, one floor, receipts only append.
This overlays the playground. It does not annex the plant, the DMV, or the clinic.
Vault locked. No MIC line.

## Stations (chassis = one Unity + one hall deploy)

| Station | Kind | Puts on the chassis |
|---|---|---|
| 1 Frame | Architect | five rooms, colors, cuts |
| 2 Inspect | residual-ring | SHA + live curl |
| 3 Safety | secret-scan | no keys in the pile |
| 4 Status | Foreman | /site/status |
| 5 Ledger door | Gate carpenter | /u /hooks /pay isolate |
| 6 Proof | Replay tester | HMAC 400/200/duplicate |
| 7 Fold | Projection auditor | rebuild == now |
| 8 Vault | Vault clerk | flag false until Seat |
| 9 Receipt | Chain notary | WAIT_GRANT hash |

The chassis does not skip station 6 to get a paint job at 8.
A finished station stays staffed (persist). The next station is a handoff.

## What the line is allowed to recreate

- Hall walk, Unity fields, KYC badge, Look $0, invited device runtime.
- Watchdogs a stranger can hash.
- Same Unity on web and app.

## What the line is not

- A second Earth run by isolates.
- Command of Passport, OHIP, a factory PLC, or a gun registry.
- Opening Checkout to "finish the line."
- Military-industrial anything.

Necessity adds a station. The Seat starts and stops the belt.
