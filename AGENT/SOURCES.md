# Source classes

Stamp: 2026-09-23T14:50Z
Watch: `unity:harvest.watch` + `unity:sec.watch`
Aggregator law: `AGENT/AGGREGATE.md`.
Privilege: harvest writes packs. Harvest does not invent a cite.

Look from all sources we can keep. Then the pages those sources point at. Then stop.
Deep is not dark. Dark is a parked class until a Tor gateway exists and a watchdog allowlists the host.

## Layers (walk in order)

| Layer | What it is | Live on this factory? |
|---|---|---|
| 0 Surface | Public HTTP(S). League sites, club sites, government pages, news wires, GitHub raw. | yes |
| 1 Door | The named public URL on a card (Players page, standings, course site). | yes |
| 2 Derivative | What that page cites: roster PDF, JSON feed, archive snapshot, social post with a date. | yes, one hop |
| 3 Deep-public | Behind a login that is still a public org tool (TeamSnap / SportsEngine bind). | yes if the door is public or the Seat bound |
| 4 Archive | Wayback / cited mirror of a layer 0–2 page we already named. | yes |
| 5 Onion | `.onion` hidden service. | **parked** |

Parked means: stamp `class: onion` + HOLE. Do not fetch. Do not paste a host. Do not claim a crawl.
GitHub runners have no Tor. This chat has no Tor. A live onion harvest today would be a lie.

## Allowed cite classes (hockey / golf / news / rooms)

- Official league (OMHA, OWHA, ALLIANCE, GTHL, NOHA, OHF)
- Club site
- TeamSnap public Players URL
- SportsEngine / other roster tools the club actually uses
- Course site (golf — the course page first)
- Municipal / school-board public pages
- News wire / official release
- Archive.org snapshot of a page we already named
- Social post only as a pointer to one of the above, with a date

## Denied (never a pack)

- Stolen dumps, credential shops, market listings
- Anything that would put someone else's private papers in a public repo
- Invented surnames to look finished
- A `.onion` URL as if we fetched it
- A second hop off a derivative that the first page did not name

## How a harvest walks

1. Name the grain (team, course, board, wire).
2. Try layer 0, then 1, then 2. Cite the URL that answered.
3. If the list is empty and the door is public, keep the empty card. That is a door, not a fail of aggregation.
4. If the only alleged source is onion, write `HOLE class=onion` and move. Do not invent layer 0 to cover it.
5. When a league's list is done, thin that search. Do not general-search a finished league.

## Coffee-shop line

We look everywhere the fact is allowed to sit.
We do not climb into a basement we cannot keep a receipt for.
If it only lives on an onion, we say so and leave a hole — we do not pretend we went.
