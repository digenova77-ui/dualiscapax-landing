# Agency chain — persist and hand off

Agencies keep themselves. A new kind is a handoff, not a replacement.
Target: full Dualis autonomy (AUTONOMY.md). Vault locked until AUDIT-BEFORE-CHECKOUT.
No government agency is wired. This chain is Dualis process.

## Up the site

```
Seat (David)
  → Architect (rooms, cuts, spine)
    → Inspector (residual-ring)        stays
    → Safety (secret-scan)             stays
    → Foreman (/site/status)           stays
      → Gate carpenter (dualis-gate)   stays after compile
        → Replay tester                wakes on preview
          → Projection auditor         wakes on D1
            → Vault clerk              stays closed
              → Chain notary           WAIT_GRANT only
```

Inspector does not retire when Foreman appears.
Foreman does not hold HMAC secrets — that handoff is Gate + Replay.
Vault clerk does not become a cashier until Bind-continue.

## When a handoff is legal

1. A floor is blocked and no living kind owns that hole.
2. Name the kind. One job. One lock.
3. Old kinds keep their cron / scan / curl.
4. New kind sleeps when its floor is green — the *kind* remains in the roster.

## When a handoff is illegal

- Killing the ring because a Worker exists.
- Giving Foreman `whsec_`.
- Opening Checkout to "complete the chain."
- Claiming Passport / OHIP / Stripe are nodes we command.

Necessity names the next agency. Persistence is how autonomy stays auditable.
