# Handoff chain

A floor is blocked and no living kind owns that hole.
Name the kind (one job, one lock).
Old kinds keep their cron / scan / curl.
New kind sleeps when its floor is green (the kind remains in the roster).
Necessity names the next agency.
Persistence is how autonomy stays auditable.

## Every handoff must also name the one story

Read AGENT/ONE-STORY.md.
Write: live URL, `<title>` on `/`, Workers+routes that own paths, Pages project.
If git draft ≠ apex, say so. Do not ship a second homepage.

## Forbidden

Killing the ring because a Worker exists.
Giving Foreman `whsec_`.
Opening Checkout to "complete the chain."
Claiming Passport / OHIP / Stripe are nodes we command.
Replacing the live face because a chat asked to elevate, curtain, Pinata, or unify.
Dropping `www` or origin-join routes without Seat.
