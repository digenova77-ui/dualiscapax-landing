Unity Framework Standard — UFS-0.1 (bootstrap)

Status: Draft beta · holder-first
Scope: One Unity ID graph first; same core laws for later principals.

Core laws

IDLaw
L1Account sovereignty — Control only over the holder’s Unity ID, binds, and explicit grants.
L2No adjacency authority — Shards, fusion, or shared pipes never control another account.
L3Admit only legitimacy — Validatable, trackable, citable, logic-legitimate.
L4Black / white ledger — Black never revealed; white only under grants.
L5Equal access obligation — Same published rules; no founder lane in policy.
L6Fail closed — Uncertainty denies side effects.
L7Intake is holder-fed — No crawl mandate; pull when needed, still through gates.

Principal Zero

First holder is the reference graph: issue a Unity ID (UIN-01-…), bind only what the holder chooses (devices, wallets, agents, people), grants empty until explicit. Not “admin of everyone” — admin of one account under the same laws every later account gets.

Unity ID (shape)

UIN-01-XXXXXXXX
  UIN   = Unity Identity Number
  01    = scheme version
  XXXX  = Crockford-ish entropy (no ambiguous 0/O/I/L)

Optional later: did:unity:01:… for DID alignment.

Wallet / ID fusion

Wallets are links, not the principal. Bind by signature challenge where possible. Roles: treasury · ops · agent · receive. One Unity ID → many wallets; agent limits stay narrow.

White / black ledger

ClassRule
BlackNever reveal, never clear-text on shared plane (e.g. full ID numbers, card images, raw secrets).
WhiteNeed-to-know assertions shareable under holder grants (e.g. “asserted valid at time T”, jurisdiction class).
GreyHolder-internal only.

Sensitive credentials: prefer local or authorized validation that emits white only. This site does not collect health-card numbers.

Admission gates

ACCEPT iff structure ∧ types ∧ integrity
         ∧ provenance ∧ policy
         ∧ black not exported

Access

ALLOW on resource iff
  owner == session.principal
  OR explicit grant (owner → session, action, scope)

Layer and data control: granular or encompassing — holder’s choice, same account only.

Networking posture (company wedge)

DualisCapax: financial + emerging AI, networked access. Open research; metered adaptive depth; settlement trackable. Token separate from company equity. DeFi leadership is a horizon; the niche is equal-access AI–value networking.

One-line standard

Legitimate, tracked, citable data under account-sovereign control; equal rules for onboarders; black never revealed; no power over others by adjacency.
