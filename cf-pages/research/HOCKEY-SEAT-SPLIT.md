## Split (product law)

| | **Household seat** | **Org / club seat** |
|---|---|---|
| **Who** | Athlete + family on one Unity ID | Coach / club / association |
| **Family pricing** | Family included — **no** separate family SKU | N/A |
| **Models** | This athlete’s games + itinerary | **Weapon:** full roster (16–18) **or** lines / PP·PK / custom units |
| **Travel** (hotel/gas/carpool) | First-class (tournament weekend) | Optional, not the sell |
| **Pipe** | Adaptive connectors | **Fixed:** TeamSnap · GameSheet (never paste) · LiveBarn · Hudl |
| **Grain** | Single-seat clocks | Team-grain residual / ice-waste / F\|D |
