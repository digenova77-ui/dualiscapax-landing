## Meaning

Perfect automation = the same script, the same path, the same receipts, every time.
Tight = the script stops before it can break street, Workers, encyclopedia, DNS, secrets, vault, or the LIVE word.
A green run that ships a break is still a hole.
The bots would rather exit 16 than look broken.

## Why tight

One `/*` Worker bind overwrites the apex we were ordered to keep.
One wrangler-10000 sold as LIVE is amnesia.
One `sk_live_` on main is a rotation incident.
One DNS edit is out of this book’s department.
One mass-delete removes the encyclopedia.
One HUD-worker zip flattened onto Pages ships the wrong object.
Green that does any of those is not security. It is a break.

## Allow — automation inside the fence

- Read `LAW.CURRENT.md` first.
- Curl the street. Write receipts. Run the mill. Run the DCLM trio as verification.
- Harvest packs under a named unit path.
- Path-exact Worker joins. `apex_overwrite: false`.
- Preview-only Pages work.
- SHA-256 verify of a named zip. Refuse a HUD-worker pack as a lander.
- Fail-closed exits that write HOLE.

## Refuse — break = hole even if the script is green

- Fire `EXECUTE_DEPLOY.sh` without Pages Edit **and** operator `confirm=DEPLOY`.
- Bind a Worker to `/*` or overwrite `/` / `/index.html`.
- Edit DNS.
- Mass-delete encyclopedia, `06_ENCYC_*`, or the live site.
- `PURGE_ALL` without an explicit blank-the-apex order.
- Commit strings listed in `AGENT/NEVER-COMMIT.md`.
- Treat Drive files as scripts.
- Claim LIVE without measured `LIVE_HTTP_OK=1`.
- Cast a mill mark with no receipt.
- Flatten a HUD-worker zip onto Pages.
- Invent or rotate tokens from chat.
- Open the vault while `AUDIT-BEFORE-CHECKOUT.md` is still interesting.
- Use a fat token (Pages + Zone DNS + Workers Edit) as if it were scoped. Least privilege: Pages Edit only.
