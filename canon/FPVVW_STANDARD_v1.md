## The five nouns (same thing, five rooms)

1. **Factory** — Clock A. Git, Drive, DCLM, Iris academy. Unlimited thought. Limited only by GH 5 min / 1000 token / CF 1200-per-5.
2. **Validation** — the file is legal *before* anyone else looks: cite-or-hole, no `$`, rename-around if the public name is cursed, Home not in the diff.
3. **Verification** — a *second* process measures. `factory-verify.yml` and/or live `/sandbox`. Author may not grade author.
4. **Production** — Clock B. One additive commit Pages may swallow. ≥90 min from last B. Fast-forward only.
5. **Website** — only what a stranger can HEAD. 200 = 1. 308-self = cursed. 404 on a booked alias = not swallowed yet.

Factory is not the website. The website is not allowed to be a dump of the factory.

## Standard path of one atom

```
idea (A)
  → kennel file / copy / link plan
  → validation (seats 1–6, 15–27)
  → verification (seats 10–12)   # different measurer
  → wait Clock B (seats 8–9)
  → production push (file + 200 rewrite to FILE)
  → website HEAD (seat 13)
  → if 0: hole + new unused name; never 308-back
```

Unborn modules enter at "idea". They do not get a side door.

## Cadence (locked until a limit page changes)

- Clock A: as fast as GH/CF allow (floor 5 min for scheduled verify).
- Clock B: ≥90 min between Pages-touching commits on Free (500 builds/mo).
- Recalibrate when Cloudflare Pages or GitHub publishes a new number. Sit one notch under.
