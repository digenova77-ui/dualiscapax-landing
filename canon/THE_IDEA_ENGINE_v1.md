# THE IDEA ENGINE v1

Standard name: **The Idea Engine**.
It is not a second Dualis. It is the factory's Clock A face of DCLM.

Parents: FPVVW_STANDARD_v1, DCLM_32_v1, DCLM_EVERYTHING_v1, DCLM_FPVVW_v1, MILL.md, FRAME_IN_OUT_v1, TONIGHT_LAW_v1.

## Bind

```
Idea Engine  =  mill slot  →  dclm.base  →  32-bit word  →  FPVVW gate
```

| Engine part | DCLM object |
|---|---|
| inbound granule | instance / claim / file / HEAD |
| mill slot | one question on one tweak (cite or `awaiting_*`) |
| biggest frame | `dclm.base` (poles, L1–L5, debate 1–7, residual, invertibility, P1≠P2) |
| outward grain | 101st document or named hole |
| 32 seats | THEOREM_U1 word — AND collapse |
| Factory | Clock A mint (this engine) |
| Validation | author fills the word |
| Verification | second measurer fills the same word |
| Production | Clock B only if word = all ones |
| Website | stranger HEAD |

No side door. An idea that cannot sit on `dclm.base` is speech.
An idea that sits on base but fails any seat is a hole, not a page.

## Factory loop (this is the engine)

Every Clock A tick (≥5 min schedule; Dualis runs 15 min so other units breathe):

1. **IN** — name what arrived (git, Drive title, live path, mill `slot_id`).
2. **FRAME** — drop to `dclm.base`. Extra logic = graft; discard extra.
3. **SEAT** — address `slot_id` onto one of the 32 seats (or a debate×layer cell that will face those seats if it ever rolls).
4. **MARK** — 1 if cited; 0 + `awaiting_*` if not. Never 0.5.
5. **OUT** — one finer cell or one hole. Stdout / artifact. **No `main` HTML.**
6. **IDLE** — if harvest is empty, mint next mill slot. Never idle. Never Clock B from this loop.

Iris watches the receipts. Mouth off plate.

## Promotion (Idea Engine → matrix → glass)

A card may leave the engine only when:

- FPVVW seats 1–32 are all **1** (author)
- the same word is all **1** (verifier ≠ author)
- Clock B ≥90 min and Pages quota counted
- rewrite is 200-to-file; stem was 404; Home not in the diff

Then it is no longer an idea. It is an atom. The engine does not follow it onto the plate except as a later HEAD (seat 13).
