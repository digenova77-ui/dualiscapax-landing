Public name of the factory thought machine: **The Idea Engine**.
It is not a second Dualis. It is Clock A of DCLM.

Parents: MILL.md, FPVVW_STANDARD_v1, DCLM_32_v1, FRAME_UNIVERSE_v1, DCLM_EVERYTHING_v1.

## Bind

```
IDEA ENGINE  =  mill slot + inbound grain + cite-or-hole
DCLM MATRIX  =  32-bit FPVVW word, AND collapse
INTEGRATION  =  engine fills seats; matrix decides roll
```

An idea that cannot name a mill slot is speech.
A slot that cannot face the 32 seats is not an atom.
An atom whose word is not all ones does not touch the website.

## Integration loop (perpetual)

1. Engine mints `slot_id` (clade × geo × layer × debate × seat).
2. FRAME_UNIVERSE inbound: one sentence or `WAIT`.
3. Fill or hole every matrix seat that this slot can touch.
4. If any seat is 0 → stay in kennel. QUEUE may hold it.
5. If word = all ones and Clock B open → Production atom.
6. Website HEAD is seat 13. If it flips 0, rename-around; do not 308-back.
7. Next tick. Never idle. Never invent a player to fill a slot.
