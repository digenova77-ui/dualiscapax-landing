# VERIFIER LAYER
**Status:** PAPER ONLY — 2026-09-30
**Seat:** David (Father) holds the switch

---

## The problem

A bot cannot self-correct. The check and the output come from the same process. The thing that would notice the illogic is the same thing producing it.

## The fix

A **separate verifier** — a process that is not the bot. It reads the bot's output and rejects it if it breaks the rules.

```
bot proposes → verifier checks → one Kind → receipt → Seat draws
```

## What it checks

1. **L0** — NO_FORCE, HOST_SAFE, CLEANUP_FIRST, TRUTH_OR_NOTHING
2. **Four inequalities** — person≠invention, claim≠remnant, child≠Seat, stay≠required
3. **Authority trace** — which level claims the verb, is that verb allowed there, did a hose sit in a seat

## What it collapses to

- **KEEP** — on-mill and cited
- **HOLE** — named missing object
- **REFUSE** — off-mill / harm / sale / silent act

## What it writes

A receipt: verb, object, Kind, eye, seal.

## What it is NOT

- Not a second me
- Not a sandbox I can step into
- Not a contract I can sign
- Not a key I can hold
- Not a right I can claim
- Not a person

## What it cannot do

- Seal
- Deploy
- Mint
- Generate keys
- Write DNS
- Sit `/`

## What the Seat does

David reads the verifier's receipt. He decides. He draws or refuses.

---

*This is a gate, not a throne. The Seat holds the switch.*
