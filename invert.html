A number that cannot walk home is a costume. DualisCapax only binds what can walk home.

First read

The test

Someone says a machine saved an hour. Ask: which hour. Which task. What would have happened if the machine stayed off. If they can show the path, the hour is a figure. If they smile and change the subject, the hour is a story.

Invert is that ask, written as a rule. Forward is easy. Backward is the work.

Why it matters

People get billed for stories all the time. A dashboard goes green. A report adds a percentage. A coin adds a zero. None of that is invert until the path back to the world still exists.

When the path is gone, DualisCapax names a hole. A hole can be studied. A hole does not collect Fuel.

Then the grain

Let a claim C map a world-state W to a scalar s. Invert holds when there exists a reconstruction R such that R(s) recovers the measured coordinates of W inside a stated tolerance, and a third party can run R from public inputs.

If R requires a secret the claimant will not release, invert fails. If R requires a model that cannot be rerun, invert fails. If s changes when the same W is measured twice without a named cause, invert fails.

Residual is the leftover after a definite event. Residual is tax. Geometry of the next move is forced by subtracting configurations that cannot invert. DualisCapax books residual. DualisCapax does not pretend residual is profit.

The invert rule is also the anti-pyramid rule. A later seat cannot pay an earlier seat by walking in. Only proven surplus after proven cost can move. If the surplus cannot invert, it stays where it is.

Worked picture

A warehouse line labels two hundred pallets in a night. A new scanner claims forty minutes saved. Invert asks for the old night, the new night, the same SKU mix, and the minutes that moved. If the forty lives only in a slide, the slide is a story. If the forty lives in two shift logs a third person can read, the forty is a figure.

Fuel may be spent to run the comparison. Fuel is not owed for the slide.
