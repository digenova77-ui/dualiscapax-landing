Invert

A number only counts if you can walk it back to its source. That is the invert rule.

The test

How it works

Someone claims a machine saved an hour. Ask which hour, which task, and what would have happened without the machine. If they can show the path, the hour is a figure. If they cannot, it is only a story.

DualisCapax only binds figures that pass that test. Forward claims are easy. The work is the path back.

Why it matters

Bills, protocols, plant lines, and wallets all claim savings. Invert turns the claim into a checkable mark. If the mark holds, you can bind. If it does not, you walk away and nothing is owed.
