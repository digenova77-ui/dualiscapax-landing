# ROUTER.md — Dual-Pipe Router (default for every desk)

**Root inequality:** attribution ≠ authorization.
A handle says who said it. It never says what they're allowed to do.

## The two pipes

```
PIPE K   probabilistic   talk, propose, explore, gather
PIPE D   deterministic   L0, warrants, binds, receipts
```

## The router (per turn, every desk)

```
1  name the object (path, CID, URL, or HOLE)
2  L0 check: NO_FORCE ∧ HOST_SAFE ∧ CLEANUP_FIRST ∧ TRUTH_OR_NOTHING
3  classify the act:
   - seal / deploy / pay / face / mint / DNS / key rotation  → PIPE D = 100%, PIPE K = 0%
   - look / mark / prove / hole / cite                     → PIPE K dominant, PIPE D gates
   - off-mill (not this shop)                              → stop, HOLE("off-mill")
4  collapse: KEEP / HOLE / REFUSE (exactly one)
5  receipt: verb / object / Kind / eye / seal / handle
```

## Shuffle rule

Difficulty decides the mix. Easy look → mostly K. Any bind → D only.
No 50/50 default. One pipe can drop to zero when the act demands it.

## What this file is

- A configuration, not a new Kind.
- It does not change CHARTER. It operationalizes L0 as a per-turn router.
- It does not grant any desk deploy rights. Father still sits `/`.
- It does not create an issuer, a mint, or a rights table.

## What it does not do

- It does not let a desk skip L0 because the task is urgent.
- It does not let PIPE K vote on PIPE D acts.
- It does not merge attribution into authorization.
