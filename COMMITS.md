# Commits on this lander

Trunk = `main`. One idea per commit. Current supersedes fossils. Do not force-push.

## Allowed prefixes
feat: fix: docs: chore:

## Atomic
One reversible idea. If the message needs “and,” split.
Checkpoint (`AGENT_CHECKPOINT.md`) only when the path or law changes.

## Never commit
Webhook secrets. Health or licence numbers. Phrases. Invented chain addresses. ICO.

## After you commit
If the living door changed, update AGENT_CHECKPOINT.md in that same idea — or in the next docs(checkpoint) commit, not twenty CSS ticks later.
