## Meter

Numbers that were not in the ask stay `SEED`. P2 never graduates to P1.

Invert lives on the sheet (`yes`/`no`/`unknown` + door). The hash is a receipt
of that write — it also binds `object_name`, `nonce`, and `parent_c`.
A child write takes the prior receipt as parent. Mid-run stays mid-run.
