# DualisCapax Read-Only Alpha — Design Direction

## Direction

**Name:** The Handoff Constellation

**Intro:** A calm cosmic operations surface where every capability is visible, bounded, receipt-backed, and transferable. The design treats decentralization as a user-facing product feature: the system should explain itself, export itself, and relinquish control after handoff.

**Probability:** 0.08

## Design movement

Editorial technical instrument: observatory clarity over cyberpunk spectacle. Use a dark field, precise status color, large readable type, and quiet orbital geometry that suggests connection without implying mystical authority.

## Core principles

1. Truth before theater: distinguish live, local, simulated, hole, and wait-grant states.
2. Capability is scoped: every connector shows what it can and cannot do.
3. Handoff is visible: export, successor, revocation, and receipt belong in the main flow.
4. Soft power: the interface is confident but never claims sovereignty, omnipotence, or permanent agent control.
5. Accessible depth: dense operational detail is available without making the first read dense.

## Color philosophy

Near-black navy is the ground. Pale bone is the reading surface. Electric mint signals verified read-only evidence. Warm amber signals a pending grant. Coral red is reserved for a genuine failure, not an unavailable future route. Violet-blue carries the cosmic/constellation accent.

## Layout paradigm

A wide observatory frame: compact header, split hero, central pipeline rail, status grid, handoff card, and a final legal/truth boundary. On mobile, collapse to one column with the pipeline remaining readable as a vertical sequence.

## Signature elements

- A three-node orbital mark with an open center: Father/kernel authority, Unity ID handoff, and independent audit.
- Four-stage pipeline rail: Claim → Fetch → Collapse → Receipt.
- Small “state grammar” labels: PASS, LOCAL, HOLE, WAIT_GRANT.
- A handoff card with a visible “no permanent key” statement.
- A copyable receipt hash generated only from the local simulation state.

## Interaction philosophy

One meaningful action per section. Simulate a bounded read-only run, inspect the resulting receipt, export the handoff manifest, and reset. No action implies privileged execution.

## Animation

Slow orbital drift and a restrained shimmer only in decorative elements. Respect `prefers-reduced-motion`. State transitions are explicit and short.

## Typography system

Use system sans for operational text and a condensed system fallback for labels. Oversized headline, small uppercase eyebrow labels, generous line-height, and no decorative text effects that reduce legibility.

## Brand essence

DualisCapax is capacity held in balance: open/depth, public/sealed, inspectable/transferable.

## Brand voice

Warm, exact, candid, and non-grandiose. Say “not deployed” when it is not deployed. Say “read-only” often enough to make the boundary memorable.

## Wordmark/logo

Use the three-node open-center mark in `alpha-mark.svg` as the compact identity for this alpha surface. It is a flat filled silhouette designed to remain legible at favicon size.

## Signature brand color

`#76f0cf` — verified mint: evidence that can be inspected without implying write authority.
