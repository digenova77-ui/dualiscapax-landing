## What an agent does NOT see

- The how-we-got-it: residual geometry session notes, millennium working
  notes, sealed papers, agent skill handoffs, agent logic bodies,
  current model state folders, the encyclopedia, the legal rollout,
  the master seal list, the Cloudflare sentinel zips, the Helix build
  plan, the unity-framework version zips, the audit ledger.
- The solution path: any file that shows how a result was reached,
  not just what the result is.

## The rule

> An agent reads the three files. It does not search the Drive.
> It does not list folders. It does not follow links out of the three.
> If a task requires something not in the three, it names the hole
> and stops.

## Enforcement

- **Bulletin Watcher** reads only `FACTORY_BULLETIN_BOARD`.
- **Bulletin Signaler** reads the board and routes to desks.
- **Desks** receive routed tasks; they do not browse.
- **This chat (coordinator)** may read the full Drive on the Seat's
  behalf, but it does not hand agents more than the three.

## What this is not

- Not a deletion. The full Drive remains the Seat's record.
- Not encryption. It is a visibility split: the Drive is unchanged;
  the agent's view is narrowed.
- Not a new Kind. It is a PATH_ALLOWLIST for reading.
