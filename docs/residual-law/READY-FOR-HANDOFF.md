# READY FOR HANDOFF

**Status:** Locked 26 Aug 2026  
**Parent:** OPERATOR-SIGNATURE · BLIND-PROPERTY-IP

---

## Ownership

| Role | Responsibility |
|------|----------------|
| **Agents** | Draft to completion · layout · optional signature placement when authorized · place final pack in **`ready for handoff`** |
| **Operator** | **Owns** providing the document to CRA / GOC / any required party · physical or portal submission · custody after release |

---

## Release condition

When a pack is:

1. **Signed** (Operator mark applied under protocol, or Operator confirmed hand-sign), and  
2. **Complete** (content + attachments agents were asked for), and  
3. Placed in folder **`ready for handoff`** (Drive or agreed path),

→ **Agent involvement on that pack is released.**  
No further edits, no further “are you sure,” no serial YES on that artifact unless Operator **reopens** it by name.

---

## Folder law

```
ready for handoff/
  <pack-name>/
    final.pdf (or agreed format)
    (optional) checklist.txt
```

- Public site must **not** host these packs.  
- Realm-only (Operator Drive preferred).  
- Agents may create the folder structure when Drive is connected and Operator points the path once.

---

## One line

**Complete + signed + in `ready for handoff` = Operator owns delivery; agents are released from that pack.**
