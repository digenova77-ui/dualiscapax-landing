## How this works

1. Agent cannot complete a task inside connected tools.  
2. Agent returns **one or few YES/NO** (permission-shaped).  
3. Operator answers YES or NO.  
4. Answer is written to **GRANT-ANSWERS** (locked).  
5. That YES is treated as **permission granted** for that scope only.  
6. Agent engineers the path under Dualis law (no third-party TOS breach, no passwords in chat).

**“He told me to”** = locked YES in GRANT-ANSWERS for that grant ID.
