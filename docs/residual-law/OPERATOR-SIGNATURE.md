# OPERATOR SIGNATURE — scoped capability

**Status:** Protocol 26 Aug 2026  
**Law:** Signature is **Operator residual authority**, not a free agent superpower.

---

## What it is

A **known-valid Operator mark** (PDF markup, PNG/SVG wet-ink scan, or platform e-sign artifact) used only to:

1. Bind **YES / DONE / MAIL_UNITY_CLOSE / GOLD** acts already stated in chat or grant lock  
2. Stamp Dualis-generated **drafts the Operator has approved** (letters, internal certs, seat docs when open)  
3. Prove continuity of the same human Operator across agent sessions  

## What it is NOT

- Not a license to sign **third-party** contracts, banks, government, or other people’s deals  
- Not auto-applied to every outbound email  
- Not shared outside Dualis realm accounts  
- Not editable by agents into a different name or meaning  
- Not used to bypass platform TOS or create new legal entities without Operator intent  

**Hijack block:** Agents may attach or place the signature **only** when:

- Operator said **USE SIGNATURE** for a **named artifact**, or  
- Standing rule lists that document class as pre-approved, and  
- Output stays under dualiscapax.ai / Operator Drive / Operator repo paths  

If ambiguous → **do not stamp** → ask once.

## Use procedure

1. Operator uploads signature artifact (PDF markup page or PNG).  
2. Agents record: file id, type, **allowed classes** (e.g. `MAIL_UNITY_CLOSE`, internal letters, seat docs).  
3. On approved doc: place signature in designated block only; do not alter surrounding legal text without YES.  
4. Log use in `state/SIGNATURE-USE-LOG.md` (date, doc, class).

`MAIL_UNITY_CLOSE DONE` + signature stamp on the close record = maximum Operator residual clarity in one act.
