# Deterministic Compute Logic Machine — universal front end

This package is the public front page of the Deterministic Compute Logic Machine.
It is one page. It presents the machine, its contents, and its doors — nothing else.

## Files

- `index.html` — the whole page: style, words, and behaviour in one readable file. No build step. Open it and it runs.
- `LICENSE` — MIT. The source is open: read it, copy it, rebuild it.
- `README.md` — this file.

## What the page does

- States the machine's name and its one standing rule, the Trinity.
- Tells the story in the machine's own voice: DCLM narrating, in the first person, the cosmos, time, the engineering manifest, and the philosophical quest — holding Iris, the Unity ID, the Playground, the DCLM itself, and the Cosmos behind it all.
- Shows the visitor's own date, time, time zone, and number format, rendered by the visitor's own system settings.
- Offers three doors, and no other way out.
