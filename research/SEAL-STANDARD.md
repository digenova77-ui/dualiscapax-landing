# SEAL standard — research surface (v1)

**Law:** Every domain journal entry on the DualisCapax residual plane follows the ALS report machine.

## Required panels (same order)

| # | Panel | Requirement |
|---|--------|-------------|
| 01 | Simulation imaging | One pane; educational / literature trajectories or residual metrics; not patient PHI |
| 02 | Pharmacology · 3D | Public structures (PubChem / literature) where applicable; class notes for biologics/ASO/vaccines |
| 03 | Full report | Scope, disease/organism frame, evidence spine, residual rules |
| 04 | Serial index | Parallel keys: domain · entity · agent · trial · endpoint · constraint · cite |
| 05 | Citations | Primary literature / labels / NCT / PubChem — no rumor as spine |

## Hard constraints (SEAL)

- Not medical advice. Not a cure claim. Not veterinary prescription.
- Open face refuses cure / eradication language without primary evidence.
- Population and species must be declared or entry fails floor test.
- DualisCapax projected columns are model-labeled, never regulatory findings.
- Same door: no founder Exempt on research depth labeling.

## Expansion rule

Seed index → pack JSON → report HTML (ALS template).  
Depth increases under residual cost when rails are live; catalog stays complete on the open face.
