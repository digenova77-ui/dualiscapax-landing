# Two-city micro test — same IDs, then a chart
2026-08-26 23:53 EDT
After city 2 exists we can hand both mayors a matched pair: efficient where / inefficient where. Not a vibe. Not a CMA vs CSD. Not tonight — Belleville is not empty and Quinte West is not started.

## What is allowed to sit on the chart
Only IDs that exist in **both** cities with the **same viewpoint and scope**.
Examples that will bind if QW is filled the same way:
- levy per household (if both print it)
- police AUTH vs DEPLOY gap %
- fire volunteer target vs now
- industrial DC $/sqft urban
- water first-block $/m³
- hire-mode species present (rolling / freeze / OT-plug)
- local-GC ↔ hospital-family association (yes/no + bid vs award)

## What is not a row
- Belleville TS capacity vs a city that is not on that station
- County paramedic $ dumped into the city levy column
- P&G headcount vs a city with no P&G
- Sunshine names vs FTE
- One city’s analog parked number

## Chart law
Each row: metric ID · City A value · City B value · gap · whose book pays. Dual view stays dual — two rows if AUTH and DEPLOY both exist.
“More efficient” = smaller residual on that ID after scope matches. Not a single score. Mayors get the table, not a ranking trophy.
