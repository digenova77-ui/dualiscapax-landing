# INVARIANT — the logic that has not failed
2026-08-27 01:02 EDT
Lock.

## What has not changed since the first four cities
Existence before number.
Grain before mash.
Species before department word.
STRONG / WEAK / ABSENT before a rank.
Clock before "always on."
Two books stay two books.
Identify at proof, same pass.
Residual is named waste, not a vibe.
$$C_{dual}=(S_A+S_B)\times B-R$$ is the score, not a new score per continent.
UNLEARNABLE stays UNLEARNABLE (Saturday path, atom without a handle).

## What is allowed to change
More rows. More stamps. A new species when two animals were hiding.
A recipe so the next row is free.
Not a seventh node type. Not a soup model. Not a headline prior.

## Failure test
If a later rung needs a different brain, the invariant broke — go back to Belleville and find the skipped split.
If the later rung only needs another cell, the logic held.

## Agent rule
Do not invent a Mars physics because Earth felt small.
Apply the same walk. That is the confidence.
