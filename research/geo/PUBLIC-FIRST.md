# Public first
2026-08-26 23:01 EDT

The index is not only for-profit shops.
It is every public-facing entity in that geo where a residual can be named.
**Publicly funded first.** Those costs sit on the taxpayer, the province, and the country.
A corporation can fund its own waste. Dualis may point at that in public. It is not the first queue.

## Classes (priority order inside a geo)

1. Municipality as operator (city/township itself)
2. School boards
3. Hospitals / health networks
4. Colleges, conservation authorities, housing, transit, police/fire as separate entities when they file as such
5. Crown agencies sitting in that geo
6. For-profit last

Same index key. Same passes. Same serial-validate. A board is an instance, not a vibe.
