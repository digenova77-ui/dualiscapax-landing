# Event timing vs engagement
2026-08-26 23:16 EDT
In a couple of months Dualis should be able to say whether a public date is the best week — not a vibe. Tonight that verdict is closed. The inputs are not.

## Verdict later needs

- City / tourism event list (ON only; IL calendars are the wrong city)
- School calendar + March break + exam weeks (HPEDSB / ALCDSB)
- Loyalist term start / reading week / end (ridership already proved sensitive)
- QSWC load + Senators home slate
- Weather / waterfront season on the Bay
- 401 + VIA weekend peaks
- Competing same-weekend events (county fairs, PEC, Quinte West)
- Construction (Bridge St E through winter 2027)
- Transit hours (no statutory-holiday service)
- Hotel / short-term occupancy if a public book exists

Stack those on the amenity + sector index. Then a date is scored against last year’s same week, not against a slogan.
