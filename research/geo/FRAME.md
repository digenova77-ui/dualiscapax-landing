# FRAME — complete without numbers
2026-08-27 00:43 EDT
Law.

## What the plate actually is
A map of *what exists* and *how those organs relate*.
Not a spreadsheet of last year's litres.
If we blank every X tonight and the IDs, grains, stamps, overlay classes, split-pairs, and Δ gates remain, the plate is still complete.
The numbers are a run against that map when someone asks.

## Three layers (do not smash)
1. **Existence** — does this organ grow on this body? SEALED-handle | N/A | HOLE | WAIT | UNLEARNABLE
2. **Relation** — STRONG / WEAK / ABSENT vs atom, vs ceiling, vs sibling. Split-pairs. Tenant-beside-civic. CMA ≠ CSD.
3. **Value** — X pulled at question-time from SRC. Cache optional. Disposable.

Layer 1+2 are the product. Layer 3 is a test.
Correlation that depends on layer 3 before 1+2 is noise.
The Quinte West mock already ran on layer 2 (OPP vs municipal police) with almost no layer 3.

## Blank-and-fill
Erase every dollar and every headcount.
A later run is valid if and only if:
- every PLAYGROUND family has an existence stamp on that CSD
- every WEAK word is split or refused
- every SRC is named so the pull knows where to go
- Δ gates still refuse illegal pairs
Then populate only the IDs the question named. Do not refill the warehouse "because we might need it."

## When a new organ appears in the incoming data
If the file cannot hit an existing ID, cut an ID *then* pull. Do not invent a column and call it measured.
If the file hits an ID but the overlay class was wrong (we called ABSENT, the organ is there), the defect was layer 1 — fix the stamp, then fill.
Data does not define meaning. Meaning is already on the ID. Data hits the mark or it does not.

## Precision owed (depth is here, not in more decimals)
Deeper = more organs named, more species split, more ABSENT declared, more SRC attached.
Deeper ≠ more cached digits.
A 2024 NBV to the dollar on the wrong grain is shallower than a blank cell with the right ID and N/A.

## Test
Ask: "what is this city's police species, water-plant species, renter-share species, capital-city flag?"
If the frame can answer without opening a budget PDF, layer 1+2 work.
Then, if the question wants the levy, pull SRC and stamp a cache.
If the frame cannot name the organ, the framework is incomplete — not the database.

## Agent rule
Build and repair the map. Pull on demand. Do not babysit a lake.
