# Index first — table later
2026-08-26 23:00 EDT

We are not building the spreadsheet.
We are **itemizing what can be measured** and giving each item an index key.
A table is only a later projection of that index.

## Two ways an item arrives

- **Serial** — one shelf, then the next (claim → independent second → book or keep possible)
- **Parallel** — several shelves opened at once for the *same* index key, then New drops echoes

Both write the same index. Neither writes a formatted report as the source of truth.

## Index key (minimum)

`geo / legal_or_trade / what_is_measured / vintage / rank`

If we cannot name those five, we do not know what we are measuring.

Examples of `what_is_measured` before any dollar:
- municipality exists (G0)
- employer-location count (G1)
- legal name present on a register (G3)
- NAICS/licence class (G4)
- a public money line (G5)

G0 Ontario is already an index of 444 geo items. That is itemization of *places*, not a business table.
Do not skip to dollars to make a grid look full.
