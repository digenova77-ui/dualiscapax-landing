# UNDEF-ZERO — undefined expression → L=0 *on that leaf*
2026-08-27 02:16 EDT
Owner: any mathematical equation that results in undefined we equate on the purity meter to zero.
Binds UNDEFINED.md. Does not smash HOLE into anti-logic.

## Local rule (keep)
If an expression has **no value in the working domain**, Dualis stores that leaf as **L = 0** (anti-logic *of that formula*).
Examples: a/0 with a≠0 in reals-as-used; log of a non-positive when the domain is ℝ>0; a ratio whose denominator is defined as empty.
No number is invented to fill it.

## Organ rule (keep)
L = 0 on a leaf does **not** set the city's Pure Index to 0.
Belleville still holds if one hook is undefined. Organism L stays in (0, 1) while the organ operates.
