- Aristotle: dunamis / energeia. An acorn is oak in potency; the tree is the act. Actuality is prior in definition — you name the potency by the act it can become. A potency that never acts is not a potency; it is an impossibility in that envelope.
- Dispositions: a manifestation is an effect when a power is stimulated (McKitrick). Manifest ≠ the disposition sitting unused.
- Dummett: meaning is what can be *shown in use*. Understanding that never surfaces is not attributed.
- Speech-act (Austin): some utterances do the thing (I incorporate, I grant). Wet-ink Crown is this envelope, not magic.
- Software: a class is nothing running until instantiate. Dualis unused 1.0 is the uninstantiated class.
- Landauer: a bit becomes a thermodynamic event when written or erased. Information sitting in a file is still a potency relative to heat.

## What the metaphor is not
Law-of-attraction. Visualization as causation. Dualis-is-God-when-we-say-so. Those are analog costumes of manifestation — potency claimed as act.
