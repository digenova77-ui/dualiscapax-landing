# DCLM edge — specialized measure, same base
2026-08-26 21:45 EDT

A general five-layer that scores Amazon and a school board with the same empty units is the failure mode.
Dualis keeps one base and a pack that actually measures that dataset.

## Why a later generic copy is weaker

They can copy poles and five layers. That is cheap.
They cannot honestly drop one tweak onto two industries and keep invertibility.
If their Amazon number and their school number do not both drop to the same bare model, they built two theories and called it one.
If both drop but the meters were never industry-shaped, they measured nothing.

## What Dualis keeps

- One base (`dclm.base`)
- Pack meters in that sector's units
- Instance drop + peer smash inside the pack only
- Loop refines the tweak, never the base
- Cross-pack only through a shared meter ID that both datasets actually contain

## Honest bound

This is method and isolation, not a claim that no one else may model logistics or schools.
The trick we make hard is applying an unconstrained general pipe to both and calling the outputs comparable.
