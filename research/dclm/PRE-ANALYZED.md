# Pre-analyzed complexity
2026-08-26 22:40 EDT

The chair is the same act for a day camp and a launch operator **if** the empty meters were already listed from public sense before anyone sat down.
That is what "not that much more complex at the table" means. It does not mean the datasets are the same size.

## Before they sit

Oracle on the named instance:
- class / subclass slots that kind of work uses
- which of those slots already have a public cell
- completeness grade
- missing-fields page if ≤ D

Then the meeting is: fill or confirm, smash, issue the dated cut.
The camp and the operator get the same verbs. They do not get the same questionnaire or the same next_cut.

## Honest limit

Pre-analysis removes *surprise about which questions exist*.
It does not remove a 400-page filing, a grant that never arrives, or a cell that only lives in the 101st document.
If we did not pre-sense the slots, the operator chair feels like a new universe. That is Dualis being late, not the model changing.

No public cell on that launch name → we still do not speak as if we scored a launch.
