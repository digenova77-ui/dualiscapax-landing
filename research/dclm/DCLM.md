# DCLM — DualisCapax Logic Model
Law version: 2026-08-26 21:40 EDT
Status: Binding skeleton for every monitored metric
Public name: DCLM. Not 2P5L on the open face.

One machine. Domain dictionaries change. Poles do not.

## Invariant (every domain)

Two poles, five layers, seven debate levels, one residual unit, one invertibility check.

| Piece | Rule |
|-------|------|
| Pole A | Constraint inside the object (genotype, phenotype, statute, policy text) |
| Pole B | Constraint outside the object (stroma, host, budget cycle, board process, delivery) |
| L1 | Inputs / ligands / statutes / data feeds |
| L2 | Transduction / workflow / kinase-or-process cascade |
| L3 | Transcription / policy interpretation / narrative switch |
| L4 | Effector / cell fate / decision executed |
| L5 | Closed loop / population / microenvironment / institution |
| Debate 1–7 | Definition → marker → modality → endpoint → regulator → access/cost → graft-risk |
| Residual unit | Cost of being wrong on this leaf, named in the leaf's units |
| Invertibility | Can the system walk back to the pre-state without new graft |
| Dual path | P1 public residual only · P2 model M only · never present M as P1 |

A metric that cannot name Pole A, Pole B, residual unit, and invertibility is not on DCLM.

## How a new case is ingested

Someone says "what about this cancer" (or this board, this nerve).

1. Load the domain dictionary (oncology | neurological | school-board | …).
2. Load the aggregate encyclopedia of every sealed leaf in that domain.
3. Map the new object onto the same metric IDs. Do not invent a new theory.
4. Fill P1 from public residual until ALS-height. P2 stays labeled M.
5. If a metric ID has no public fact, status = `seed`. If Drive body exists, `lifting`. If ALS chrome is live, `live`.
6. Compare against nearest neighbors in the aggregate (e.g. new HRD solid tumor → ovarian + PDAC-HRD rows, not a blank page).
7. Output: leaf HTML + pack JSON + delta vs aggregate (what is the same machine, what is a new residual class).

The encyclopedia is the memory. DCLM is the meter. The leaf is the public sentence.
