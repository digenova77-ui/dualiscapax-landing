# Two-pass geo — general then specific
2026-08-26 22:49 EDT

A general search is the first pass only.
The second pass is specific hunts that surface what the first pass missed.
Same structure for every Ontario district after Belleville.

## Pass 1 — general (denominator + coarse list)

- StatsCan Business Register counts for that CSD (employer size + NAICS). Belleville order-of-magnitude: Townfolio reprint of Mar 2024 BR size bands sums to ~1,860 employer locations (1–4 employees is the mass). Use current StatCan table when harvested, not this reprint as gospel.
- OBR basic search constrained to the city/legal name patterns.
- City / chamber directory dump (trade names).
- Municipal licence classes (operating subset).

This pass sets a **target count** and a dirty name list. It is not the census.

## Pass 2 — specific (what general hid)

Serial slices, one at a time:
- One NAICS / one street / one licence class / one legal-name prefix
- Names on the directory that never hit OBR (trade name ≠ legal name)
- OBR actives with no directory row (registered, maybe not customer-facing)
- Federal corps with a Belleville registered office
- Charities / societies / camps
- Principal-platform hard numbers, then independent second cite

Stop only when pass-2 slices stop adding names and the live list is in the same order of magnitude as the BR denominator — or the gap is **named** (unregistered operators, empty-shelf classes).

## Two flags per name

- **Registered** — OBR / federal / extra-provincial status
- **Operating** — licence, recent filing, payroll-class BR inclusion, dated public activity

Registered ≠ operating. Both can be empty. Both can be unsearched.
