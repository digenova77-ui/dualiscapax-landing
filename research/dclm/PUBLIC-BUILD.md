# DCLM public build — know it before you score it
2026-08-26 21:55 EDT

Running a model against a firm Dualis has not read is futile. WAIT.

## Two asks

**A. Internal residual (default)**  
They did not ask how they stack up.  
Load only this firm's data + this firm's tweak.  
Target: residual loss **inside** that structure. That is the ultimate tweak Dualis is trying to find.  
Peer tweaks stay off the run. Amazon cost constraints stay off.

**B. Industry stack-up (only if asked)**  
"How do we stack up" / "compare to the industry" → fair game.  
Load every other **in-sector** firm tweak Dualis actually has as its own instance.  
Run each. Smash. See which meters and moves help **this** onboarder.  
Output is still this firm's next action, not a public league table, not Am-Mart.

"Better" means lower residual against the ask they named — not Dualis crowning a winner on the website.

## Template vs opponent

Amazon tweak as template shape: always available, carries no Amazon numbers.  
Amazon tweak as opponent: only in ask B, and only meters both operate.

## Bottom-up after many firms exist

Firm tweaks → surviving shared meters → sector tweak → industry tweak.  
Sector tweak is an aggregate of fills, not a reason to skip the firm's own residual hunt.
