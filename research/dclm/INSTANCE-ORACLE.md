# Instance oracle — one name, money + operations
2026-08-26 22:43 EDT

An oracle is assigned to a legal name.
Its only task: public financial and real-world operational facts for that name.
It does not wander. It does not write takes. It does not merge Tesla into SpaceX because the same person talks.

## Avenues (after SOURCE-ORDER 1–2)

- Wire and trade press that quote a filing, a launch, a permit, a contract award
- Range / FAA / FCC / NASA public dockets when that instance uses them
- Their own site and letters (self-disclosed, labeled)
- Secondary summaries only as pointers — the cell still needs the primary cite

A headline without a number or a docket is not a meter.
Rumor that "costs fell" is not a meter.

## Continuity

The oracle is not a one-shot binder. Tomorrow's notice moves vintage (INVALIDATION).
Dualis does not have a live SpaceX oracle covering every avenue tonight. The assignment law is already this: if the instance is held, something is tasked to watch the shelves that can fill its meters.

## Output

New cite → cell + date + rank (exchange / register / self-disclosed / news-pointer).
No cite → no cell.
