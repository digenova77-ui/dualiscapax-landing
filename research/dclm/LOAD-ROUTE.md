# DCLM load route
2026-08-26 22:00 EDT

## New object (never seen)

1. Learn the thing: structure, spend, micro and macro that actually attach to it.
2. Find external references (filings, public record).
3. Find Dualis references (tweaks already run).
4. Load those prior tweaks as **priors** (M). See if the shape applies.
5. Do not replace a prior tweak. Mint a **new** tweak named for this object.
6. Score this object only on this object's data.

That standard is for every tweak Dualis ever mints.
The index grows on purpose: one row per tested object, then sector rows that rise from survivors, then industry rows that rise from sectors, then bare DCLM.

## What to load when they ask

| ask | load |
|-----|------|
| this company / this team / this board | **only** that named tweak. Skip sector. Skip industry. |
| this sector | the sector tweak + every child tweak Dualis actually has in that sector |
| this industry | the industry tweak (aggregate of sectors that already exist) |
| the logic with no object | DCLM. No tweak. |

Empty industry/sector slots do not score. "Knows everything about everything" is the target of an industry tweak after children exist — not a pre-written blob.

## Priors never overwrite

Amazon's tweak stays Amazon when Walmart is minted.
A prior may explain where to look. It may not become this object's books.
