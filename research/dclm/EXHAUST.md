# Exhaustion — empty is allowed only after the shelves
2026-08-26 22:44 EDT

"I searched the web and stopped" is not exhaustion.
Empty is a legal state only after the instance's shelves were actually opened.

## Minimum shelves before a meter may be marked empty

1. Regulator / exchange search on the **legal name** (EDGAR, SEDAR+, Companies House, the listing venue they actually use).
2. Their IR / newsroom / published letters.
3. The public docket that kind of work uses (FAA/FCC/NASA, municipal minutes, charity return — whichever applies).
4. Principal-account hard numbers (M-possible if unconfirmed).
5. One more pass for the document class that often hides the line (notes to statements, exhibit, tender memo, 101st PDF).

A single generic search box is none of those.

## What exhaustion yields

- Cite → cell
- Principal-only → M-possible
- Shelf opened, nothing there → empty, **shelf named** (so the next agent does not pretend the shelf was never tried)
- Shelf not opened → not empty; state is **unsearched**

Unsearched is worse than empty. Empty is a result. Unsearched is Dualis stopping early.
