# DCLM instance protocol — drop a business onto a sector pack
2026-08-26 21:43 EDT

A sector pack is the industry DCLM. An instance is one organization dropped onto that pack.

## Drop

1. Identify pack from the sector, not from a story about another sector.
2. Load that pack's meters, units, wait-states, graph.
3. Measure this instance: n, k, complexity, missing edges.
4. Score only meters the instance can fill. Hold the rest as WAIT.
5. Compare only to other instances in the same pack.
6. Write the delta: what moved, what was empty, what was the wrong grain.
7. Refine the pack from the delta. Deeper meters come from repeated drops, not a new theory.

## Build-together

Instances in one pack become that industry's aggregate.
What the pack thinks it is measuring may change when many instances show the same empty meter or the same false grain.
That refinement stays inside the pack.

## Forbidden

Dropping a school onto amazon_ops.
Scoring a clinic with SB.REKEY_COUNT unless the same meter ID exists in both packs and both datasets contain it.
Using one famous company as the definition of the pack.
