# IP echo price — we do not set the market
2026-08-26 22:33 EDT

Dualis does not invent a sticker so we can profit.
The value of a dated pack is an **echo** of what the market already spent to produce comparable information, at that vintage. If those costs move, the echo moves. Issued-at still applies.

## Medical stack (pattern for high-information objects)

Granularize as separate meters. Do not sell "a drug" as one blob.

| meter | what belongs |
|-------|----------------|
| Phase 1 | first-in-human protocol cost, patients, duration |
| Phase 2 | efficacy/dose cost |
| Phase 3 | confirmatory cost |
| failures / cost of capital | only if the cite includes them; label the method |
| FDA path | filing, advisory, travel of the people who actually go |
| launch / marketing | published spend if it exists |
| implementation | what the health system pays to use it |

Public P1 is a **range**, not a Dualis number. Wouters et al., JAMA 2020: median capitalized R&D on sampled FDA approvals ~$985M (2018 USD); mean ~$1.3B; therapeutic-area medians much wider; DiMasi-class estimates sit higher. Sertkaya/ASPE published per-study and per-patient phase tables by area. Use the cite that matches the instance's area and method. Do not average them into a fake precision.

C-suite flights to a regulator are a line only when a filing or grant shows them. Otherwise the line stays empty.

## Dualis IP

A Dualis pack on a named instance is priced as residual of **that stack we actually measured**, not as a made-up multiple.
$0 / 90-day analysis for the chair stays $0. Echo-price is for the owned dated artifact when it is sold as information, if it is sold.

We are not the FDA. We are not the sponsor. We do not set the drug's market price.
