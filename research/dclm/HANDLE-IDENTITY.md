# Handle identity — context first
2026-08-26 22:46 EDT

"Is this account them?" is not answered by the account.
It is answered by walk-back to facts Dualis already holds on that person or instance.

## Why

A bio that says DualisCapax is a claim. A lookalike handle is a claim.
Clarity exists only if independent cells already on the instance match the handle (legal name already used, company already named, events we already dated, an email or domain already in the pack). No prior context → we cannot know. That is unsearched identity, not confirmed principal.

Same rule as POINTER-VALIDATE: the mouth asserting "this is me" is not a second cite.

## For principals of an instance

Validated principal = handle + walk-back to the instance pack.
Until that walk-back exists, hard numbers from that handle stay pointer-only, not M-possible-as-principal.

This is how Dualis treats onboarder accounts and operator accounts. Not a special case for one person.
