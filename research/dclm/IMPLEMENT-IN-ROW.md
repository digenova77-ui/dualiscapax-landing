# Implementation lives in the row
2026-08-26 22:19 EDT

Philosophy: the finding is not a teaser. Charging again to hear the how is graft.
Mathematics: the cut is the same object as the residual, in the same units, with steps a stranger can execute.
Ownership: Dualis writes the plan. They do the work. We do not become their contractor unless they separately grant that.

## Vague-data law

If their feed is precise, the row is precise.
If their feed is vague, the row says **which field is missing** and stops. It does not invent a chiller curve.
We never return Dualis-made fog.

## Exact plan (required on next_cut)

| beat | must contain |
|------|----------------|
| why | the failed constraint, in their units |
| evidence | cite or their own meter walk-back |
| do this | numbered acts a tech / controller / counsel can follow |
| do not do this | the fake save |
| done when | the meter that proves the residual moved |
| hands | theirs after the page |

No second invoice to "unlock implementation." If we know it, it is on the page.

## HVAC pattern (template, not a diagnosis)

Only this tight if their BAS / work orders / nameplate data support it. Otherwise list the missing points and stop.

```
why:        [e.g. simultaneous heat/cool on AHU-12, or dirty-filter ΔP above spec]
evidence:   [their trend, date, point id]
do this:    1. …  2. …  3. …
do not:     [replace the whole plant / buy a new brand without the meter]
done when:  [kWh or °C or ΔP target, same point id]
hands:      their facilities crew or their vendor
```

A sentence like "optimize HVAC" is not a row. It is fog. Fog does not ship.

## What Dualis does not do on this face

- Hide the how behind a paid layer
- Perform the wrench work unless a later grant says so
- Fill gaps with industry averages when their instance has no number
