# Identity bond — proved locks, speculation stays named
2026-08-26 22:47 EDT

Identity of an instance (or a handle) is built only from cells that already locked: cross-validated, walk-back passes, entrenched because they are true.
Everything else is speculation until a second independent shelf makes it true.

## Containers on the entity

| state | meaning |
|-------|--------|
| Proved | independent cites; this is the bond |
| M-possible | principal-claimed, unconfirmed |
| Pointer-only | public platform claim, no principal, no second |
| Empty | shelf opened, nothing there |
| Unsearched | shelf not opened |

Speculation is not deleted. It sits in the container for that entity.
It is not booked as a meter.

## Why keep the unknown

A new proved cell can make an old unknown *mean something* (same object, same vintage, now attachable).
That is not "three rumors become a 10-K."
A cluster of unproved claims does not self-promote.
A proved cell can promote a neighbor from pointer → M-possible → confirmed when the second shelf is real.

The unknown was never meaningless. It was unnamed if we threw it out.
