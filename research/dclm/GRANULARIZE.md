# Granularize + oracle harvest
2026-08-26 22:29 EDT

Granularize is not "add adjectives."
It is find the fact on a public record that the first hundred documents never pointed at.

## 101st-document law

A value may sit in one filing, five, a hundred — or only in the 101st.
Absence of a pointer in 1–100 is not proof the fact does not exist.
Stop early and you have a slogan. Keep going and you have a cell.

If the cell still has no cite after the hunt, it does not print. Depth is not invention.

## Tomorrow

If they publish tomorrow, vintage moves.
A pack printed from yesterday's 10-K is stale the morning a material notice lands.
Harvest is continuous on *named instances we already hold*, not a once-a-year binder.

## Wait vs oracle

| mode | job |
|------|-----|
| wait | inbox / grant / they sent a file |
| oracle | outbound: registries, filings, minutes, tenders, labels, league tables, their own site |

Oracle reads **public** surfaces. It does not pick locks. It does not enter a BAS without grant.

An oracle is assigned to a named instance (INSTANCE-FOCUS). It does not wander the whole economy to feel busy.

## What ships

New public fact → cite + date + unit → existing tweak deepened or new subclass opened.
No cite → no cell.
