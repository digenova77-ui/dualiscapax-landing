# Solution architecture frameworks — map, do not wear
2026-08-26 22:20 EDT

Dualis is not TOGAF. Dualis is not a slide taxonomy. The product of architecture here is a **scored row with a plan**, then their hands.

## What the named frames actually are

| frame | what it is | what it is not |
|-------|------------|----------------|
| TOGAF ADM | a change *process* across business/app/data/tech | a drawing language |
| Zachman | a 6×6 completeness *grid* (who/what/where/when/why/how × perspectives) | a delivery method |
| C4 | four zoom levels of software pictures (context→container→component→code) | governance |
| 4+1 | stakeholder views of one system | a residual meter |
| arc42 | a documentation *template* | an engine |
| SABSA | security architecture from business risk downward | a firewall list |
| ISO/IEC 42010 | how to claim an architecture description is complete for a concern | a product |
| ADR | one decision, one page, dated | a framework |

People combine them. That is normal. Combining them is not a solution.

## Dualis bind

Their question is always an instance. Measure-first. Result face. Implementation in the row. Posture: not parents.

| their concern | Dualis object | borrowed check, not the costume |
|---------------|---------------|----------------------------------|
| Did we forget a face? | who + not-for on the atom | Zachman completeness, not the 36-cell religion |
| Can an auditor reconstruct it? | walk-back 1–5 | 42010 concern, without the standard as wallpaper |
| What do we change Monday? | next_cut numbered | not a TOGAF phase gate |
| What must stay sealed? | Seal / tenant vault | SABSA "why protect" without SABSA certification |
| How is the software drawn? | only if a row needs a picture | C4 context/container, stop before code tourism |
| Why this bind not that? | one ADR per bind | ADR |

## Forbidden graft

- Selling a TOGAF engagement as Dualis residual work
- An industry reference architecture poured onto an unnamed plant
- A diagram with no meter, no cite, no next_cut
- Architecture-as-babysitting (we stay to "govern" after the page)

If a frame does not change a unit on a named instance, it does not ship.
