## Complexity class (public, before they type)

Score from what they *govern* and what is already on the public record. Not from a sales guess.

| class | span | examples (pattern, not a client list on the site) | packet |
|-------|------|-----------------------------------------------------|--------|
| C1 | one site / one club / one school | local board school, rec team, single plant | 6 lines only |
| C2 | one board / one city service | local school board (e.g. a single Ontario board) | 6 + board module |
| C3 | one ministry / one province portfolio | Ontario Ministry of Education | 6 + board + ministry module |
| C4 | national or multi-ministry | federal department / whole-of-government surface | 6 + ministry + crown/privacy module |
| C5 | multi-jurisdiction operator | global marketplace, multi-country 10-K | 6 + operator + jurisdiction module |

If class is unclear, send C1 and let their sentence promote the packet.

## Always on (C1)

Name. One sentence to model. One meter. Existing controls (BAS / vendor / none). One suspected waste. Who can grant.

## Board module (C2+)

- How many sites sit under this legal name.
- Who pays energy / payroll / transport (board vs site).
- Existing RFP or consultant already on this object? name / none.
- Union or statutory constraint that would block a cut (one line or none).

## Ministry module (C3+)

- Statute or program name that owns the meter.
- Which lower boards / agencies actually operate the asset.
- Public dataset already published (yes + URL / no).
- Procurement path if a cut needs a vendor (existing standing offer / net new / unknown).

## Crown / privacy module (C4+)

- Personal information in the feed? yes / no / unknown. Dualis does not want SIN-class data for a cost row.
- Which crown counsel or privacy office must see the pack.
- Wet-ink still required for any outbound to another ministry? yes / no.

## Operator / jurisdiction module (C5)

- Legal entity to model (OpCo, not the brand).
- Jurisdictions in scope (list or "this country only").
- Public filing to use as P1 (10-K / AIF / annual report + year).
- Which interior system they might later grant (WMS, ads, energy, none yet).
