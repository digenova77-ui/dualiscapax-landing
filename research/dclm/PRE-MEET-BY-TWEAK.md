# Pre-meet by tweak — questions from the work they do
2026-08-26 22:26 EDT

Sense the instance from public record. Emit only the questions that fill meters that tweak will use in the meeting pack.
Do not ask a board for SKUs. Do not ask a club for a 10-K segment.

## Order

1. Name the instance (public).
2. Name the kind of work (one line: plant / board / ministry / operator / club / other).
3. Load that tweak's empty meters.
4. Ask the few questions that fill those meters.
5. Always keep the six core lines.

If we cannot sense the work, send the six lines only.

## Question packs by kind (add, do not replace the six)

### Plant / facilities / HVAC
- Utility account or interval meter already on site? which commodity.
- BAS or thermostat network name, or none.
- How many AHUs / plants they want in scope (one / list / whole site).
- Occupied hours they actually run, if they know.

Meeting answers: which simultaneous heat/cool or ΔP residual is public or grant-blocked; coordination vs vendor visit.

### Local school / board
- Number of sites in this legal name.
- Who pays electricity / gas / transport.
- Enrolment band if public (or "use the published number").
- Bus contract already in force? yes / no / unknown.

Meeting answers: site vs board residual; first cut that does not need a new RFP.

### Ministry / program
- Program or statute name to model (one).
- Operating agencies under it (list or "all boards").
- Public dataset URL if they have one they want used.
- Transfer vs direct spend for the meter they circled.

Meeting answers: which published line moves; which agency actually holds the wrench.

### Multi-country operator
- Legal entity (OpCo) not the consumer brand.
- Filing to treat as P1 (year).
- Scope: one country / one function (e.g. fulfillment energy) / whole filing.
- Interior system they might later grant (name or none).

Meeting answers: public opex residual from that filing; not a warehouse walkthrough we do not have.

### Club / team
- Level and sanctioning body.
- Ice / field / travel they pay vs host.
- Registration or gate they control.
- Volunteer vs paid ops.

Meeting answers: the one cost line they actually own this season.

## Rule

A question that cannot change a cell in the meeting pack is not sent.
