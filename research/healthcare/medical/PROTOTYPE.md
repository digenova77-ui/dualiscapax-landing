# Medical Disease Leaf — Prototype Law

**Prototype leaf:** Amyotrophic Lateral Sclerosis (ALS)  
**Journal ID:** `ED-RES-NEURO-ALS-001`  
**Pack:** `als.dual.v0` → report `ED-RES-NEURO-ALS-SIM-002`  
**Status:** **PROTOTYPE** (not merely sealed seed)  
**Law version:** 2026-08-24  

Every other disease leaf clones this machine. Disease facts change. **Density does not.**

---

## Dual column (absolute)

| Side | Content rule |
|------|----------------|
| **Public / SoC / competitor** | Maximum available public residual: approvals, withdrawals, Phase, trial IDs, labels, PubMed/CT.gov/PubChem, network meta where it exists, survival and functional point estimates with CI when published. Thin literature does **not** authorize a thin page — expand citations and trial links until the surface is full height. |
| **DualisCapax** | Simulation / closed-loop pack data only. Honest gaps labeled. Same table schema even when M is sparse. Never present model output as regulatory finding. |

---

## Required blocks (clone ALS)

1. Crumbs · catalog ID · classification line  
2. Phase / literature links (CT.gov phases, PubMed, PubChem when chemical)  
3. Where research stands (prose, public facts)  
4. How DualisCapax helps (dual-column honesty)  
5. Clinical snapshot facts  
6. Comparison table (Approach · Phase · Real-world efficacy · Dualis projected · Same principle)  
7. Molecule / entity pane (3D PubChem when applicable)  
8. Go deeper → simulation report · gated sim · AI portal  
9. Text scale control (`text-scale.css` / `text-scale.js`) on long pages  
10. Disclaimer: not medical advice · not cure claim  

Simulation report (when present): imaging pane · pharmacology 3D · full report · serial index · citations.

---

## Fill rule for thin leaves

1. Scaffold status is temporary.  
2. Auto-fill = bring external support to ALS height first, then attach Dualis pack rows.  
3. Weak simulation data → still full public column; Dualis cells stay labeled incomplete until pack depth.  
4. Oncology, infectious, cardiology, immunology, metabolic — same skeleton.  

**ALS is the prototype. Everything else rises to it.**
