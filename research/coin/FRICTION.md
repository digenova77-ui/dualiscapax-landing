# Labeled leftover

In force: no.

A gift or an allegiance bind names the leftover it is about. That name is the only place the money may go.

## Row

```
leftover = {
  label,          // the throw, the room, the issue
  sitting,        // Unity ID that bound or gave
  receipt,        // hash a watcher saw, or none
  tagged,         // published address that was told to hold this leftover
  spent,          // hash a watcher saw against this label, or none
  open            // true until spend matches the label or two checks close it
}
```

The token contract does not hold this. DualisCapax Inc does not skim it. A gift is not a purchase.

## Adequate

Spend is against that leftover only. It is not a general till. It is not a raid on the other side. It is not a billboard for a different room.

Adequate means the leftover stays open until a watcher sees a spend that names the same label, or two checks agree the leftover is closed. You do not take a gift for one throw and close a different door with it.

If a gift arrives with no leftover name, it is just a gift. No allegiance spend is claimed.

## Two checks before the hall says it happened

1. A watcher sees the tagged receipt.
2. A watcher sees the spend against that same label.

This page does not see transfers. Until both agree twice, the hall says the rule. It does not say the money moved.
