# DualisCapax Research Paper Standard

**Law version:** 2026-08-22  
**Status:** Binding for all public research surfaces on the plane  
**Scope:** Every disease page, engineering pack, energy note, field entry, philosophy surface

---

## Purpose

Highest-order detail with **one flow, one length band, one style, one integrity rule**.  
Ground-up preferred. Scaffold allowed only when labeled **seed / scaffold** and capable of bottom-up fill without rewriting the law.

---

## Residual unit of a paper

A public research document is valid only if it states:

| Field | Required |
|-------|----------|
| **Title** | Specific subject (disease, system, field) |
| **Residual unit** | What cost-of-being-wrong is being metered |
| **Law version** | e.g. 2026-08-22 |
| **Pack id** | Machine id (e.g. `als.dual.v0`) |
| **Status** | `seed` · `scaffold` · `depth` · `archived` |
| **Grade** | Open residual · Prove · Depth (gated) · Seal (never public method) |
| **Dual path** | **P1** literature-forward · **P2** constraint-bottom under model M |
| **Disclaimer** | Not medical advice / not securities / not cure claim as applicable |

Missing any required field → document does not clear residual standard.

---

## Dual path (always)

| Path | Name | Content |
|------|------|---------|
| **P1** | Literature-forward | Public programs, phases, regulatory residual, citations |
| **P2** | Constraint-bottom | Declared constraints under model M only. No Seal. No measured clinical outcome claimed as fact from M alone |

Both share: dual-column honesty, citation stubs, content hash when vaulted.

---

## Debate levels (medical and analogous elsewhere)

1. Definition / phenotype (or system boundary)  
2. Biomarker / target class (or interface class)  
3. Modality / mechanism class  
4. Endpoints / success meters  
5. Regulatory / standards residual  
6. Access / cost residual  
7. Graft risk (time already elapsed; selection bias; irreversible residual)

Each level: **seed / todo / depth** marked explicitly.

---

## Length, flow, style

| Rule | Spec |
|------|------|
| **Flow** | Kicker → Title → Subtitle → Meta → Badge → P1 → P2 → Debate levels → Footer note |
| **Length band** | Open page: dense single-screen intent on desktop; expand tables, not marketing paragraphs |
| **Style** | Journal residual UI (`medical-docs.css` for clinical; same density for engineering/energy) |
| **Acuity** | One claim per row; no padded baseline |
| **Consistency** | Same crumbs, meta, table head language across diseases |
| **Accuracy** | P1 only from public residual sources; P2 labeled model M; never B presented as A |

---

## Integrity locks (hard)

1. **Fundamental cost reduction only** — path through Dualis must compress residual, not inflate baseline.  
2. **Artificial cost inflation is absolutely impossible by design** — padded-then-discounted savings do not clear.  
3. **Overclaim is impurity** — horizon labeled horizon; sim ≠ production.  
4. **Seal stays Seal** — method opaque; Open surface complete where published.  
5. **Ontario / Canadian law first.**  
6. **No tribes preferred · All Haters Welcome · Truth and Unity Prevail** — impact only, not wallpaper.

---

## Ground-up vs scaffold

| Mode | When |
|------|------|
| **Ground-up** | Constraints declared first; literature grafted second |
| **Scaffold** | Structure and empty levels present; fill without changing law |
| **Forbidden** | Marketing chrome as science; cure language on Open face; Seal as product intellect |
