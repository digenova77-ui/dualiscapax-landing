# Serious residual glass (not cheesy hologram)

## Target reaction
“Holy smokes — this is on a different level. I should take this seriously.”

Not: “cool sci-fi theme.”

## Rules
| Do | Don’t |
|----|--------|
| Quiet dual residual atmosphere (low opacity) | Scanlines, rainbow chrome, constant sheen animation |
| Fine inset edge (blue residual only) | Thick neon borders |
| Flat professional panes; depth via shadow | Perspective skew that feels toy 3D |
| Same gravity on phone, tablet, desktop | Desktop-only spectacle |
| Medical docs stay clinical skin | Holo marketing on efficacy tables |

## Devices
- **Mobile:** tighter radius, solid panes, no hover dependence
- **Tablet:** same type system, readable density
- **Desktop:** optional `holo-elevated` soft gradient only

## Proof still not the glow
Seriousness of the face supports residual law and dual-path docs; it does not replace them.
