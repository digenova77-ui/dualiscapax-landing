# Residual path exhaustion (crawler synthesis)

## Intent
If someone enters the ALS spectrum, the plane keeps **logic with the original path** until that residual space is exhausted—bottom-up toward molecular structure—before freely branching to unrelated disease articles.

This is **curriculum residual**, not a dark-pattern prison.

## Free-will floor (locked)
| Allowed | Not allowed |
|---------|-------------|
| Recommended order, “complete this node” gates on Open | Blocking exit from the site |
| Soft lock: off-path links dimmed until checklist done | Forced medical conclusions |
| Depth tools (assemble / sim) behind residual cost when live | Claiming assembly = clinical proof |
| Always: “Leave spectrum” + search | Erasing user agency |

User can always leave. The system **refuses to pretend** a side-hop is the same residual path.

## Synthesized crawler (what it does)
1. **Index** all docs under a spectrum ID (e.g. `spectrum:als`)
2. **Graph** nodes with prerequisites (DAG, not maze)
3. **State** per session/ID: nodes visited, nodes exhausted
4. **Gate** external/off-spectrum links until `exhausted(spectrum)` OR user opts out
5. **Maintain logic** with original pack hash — drift checker rejects path text that contradicts sealed residual

## Bottom-up ALS example (seed order)
```
1 definition / phenotype
2 public programs P1 (competitors residual)
3 endpoints & graft risk
4 target classes (SOD1 subset vs sporadic)
5 constraint-bottom P2 under M
6 molecular / structural residual (Open diagrams only)
7 assembly tools (Depth — if tools + FM when live)
```
Only after 1–6 (or explicit skip) does the UI brighten “Osteosarcoma”, “Parkinson”, etc. as equal peers.

## Exhaustion definition
A node is exhausted when:
- primary residual text viewed, and
- dual-column A/B acknowledged if present, and
- optional quiz/check is **not** required on Open (optional Depth)

Spectrum exhausted when required DAG leaves are complete.

## Crawler depth
Internal only first: `research/sim/packs/*` + medical-docs HTML.  
External PubMed links: listed as **records**, opened in context drawer, not as a random walk that abandons the spectrum.

## Assembly
“Assemble if they have the tools” =
- Open: structural diagrams, constraint lists, public records
- Depth: sim / build steps under residual cost — never “you cured ALS”
