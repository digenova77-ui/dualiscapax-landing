# DualisCapax — Argument Model (Core Law)

**Status:** Fundamental. Not optional tooling. Not a temporary workshop habit.

When any two (or more) positions, systems, claims, or designs must be resolved on the plane, the **Argument Model** is mandatory residual procedure.

---

## Operators

| Step | Name | Duty |
|------|------|------|
| 1 | **State** | Put each side in a container — honest, no strawman |
| 2 | **Max Friction** | Force where they tear, conflict, or become unlawful |
| 3 | **Max Affinity** | Force where they lock, reinforce, or share residual truth |
| 4 | **Hybrid** | Crystallize what survives both runs into plane law or reject |
| 5 | **Ledger** | Write the result (decision, tier, or public spine update) |

```
A × B
  → friction run
  → affinity run
  → hybrid crystal
  → law or discard
```

---

## Scope (“argument between anything”)

Valid inputs include, without limitation:

- Business models, tokens, gateways, currencies
- Legal regimes (e.g. Ontario / FINTRAC) vs product design
- UX policies (friction gray-scale) vs AML
- Research claims vs sandbox verify under model M
- Agent behavior vs eFuse

**Not valid:** Using the model to open Seal / 2P-5L loop-back, to circumvent law, or to erase free-will personal experience.

---

## Relation to the plane spine

| Plane operator | Argument Model role |
|----------------|---------------------|
| **Open** | Publish hybrid results that are public-safe |
| **Prove** | Gateway/KYC conflicts resolved through friction/affinity before mint |
| **Depth** | Guide may run mini-arguments frame-grounded; FM pays residual |
| **Seal** | Never an output of a public argument run |
| **Friction policy** | Operational child of this law (kinds, tiers, restore) |
| **eFuse** | Argument cannot invent unbound capability |

---

## Hard rules

1. **Both runs required** before hybrid becomes law — affinity alone is insufficient; friction alone is insufficient.
2. **Law above story** — hybrid that violates Ontario/Canada is void.
3. **Split kinds** — do not mash distinct cause codes into one blunt ban without naming them.
4. **Restore path** — max friction outcomes that deny access must state restore conditions unless law forbids.
5. **Diamond test** — hybrid must read the same from research, gateway, FM, and Seal faces.

---

## One-line law

> **The Argument Model (state → max friction → max affinity → hybrid → ledger) is core DualisCapax residual law for resolving any against any on the plane.**
