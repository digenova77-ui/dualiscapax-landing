# DualisCapax Realm (DCCP)

Applications that fully function only inside this control plane.
Demand for DCCP is driven by apps, not by a global network standard.

## Layers

1. **Public shell** — landing, research journals (100% medical surface), onboarding copy
2. **Edge control plane** — Access, Fuel burn, stream fail-closed, circuit-level safeguards
3. **Realm apps** — AI portal, gated simulation, paid depth sessions
4. **Sealed vault** — method, named core machinery, sim payloads (never public git)

## Fuel

- One prepaid unit
- Burn = f(Importance) over medical + math puzzle weight
- Packs: Starter / Standard / Enterprise (capacity deposit)
- Crypto = settlement for Fuel only (Ontario + Canada + FINTRAC before live)

## AI posture

- Default: pro-human thought; no answer-key; no deeper-door push
- Multi-universe theory: fascinating discussion only if user opens it; divert; never operationalize
- Paid explicit simulation: different tier when user asks to build further (e.g. toward Phase-style work)

## Capture pipeline (unified line)

Structured events for scale (no sealed method in events):

```
event_id, ts, surface, actor_tier, fuel_burn, importance_band,
resource_id, phase_tags, public_medical_ref, stream_bytes, result_code
```

- Public medical reads may be zero-Fuel and optionally sampled
- Realm sessions always emit burn + surface + result_code
- Matrix-style capture = columnar event log for Capax Ledger; not public reconstruction of core
