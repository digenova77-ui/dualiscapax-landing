# COIN ARCHITECTURE

Most sophisticated machine, simplest door.
Engineering lives in the factory. Dualis only Looks. Desire is residual falling — not an APY.

Ticker = `awaiting_ticker`. Counsel = `awaiting_counsel`. No live mint. No Home checkout.

## Do not build a new L1

A private chain is a toy no wallet speaks.
Compatibility means an asset type phones already hold (ERC-20 class or counsel-named equivalent) plus a seed phrase wallets already derive (BIP-39 / BIP-44 when a chain exists).
WalletConnect / existing apps — not a Dualis wallet store listing first.

## Four layers

1. **Book** — THE_PLAN, PoL receipts, residual numbers. Dualis Look. $0.
2. **Root** — Merkle of cited leaves (file hash, curl code, measured unit). Light clients verify a close without the whole factory.
3. **Wrapper** — standard token the coin vehicle issues after counsel. Dualis is not the issuer.
4. **Gate** — mint only when all five PoL rules are 1. No ownerPrint(). No holding yield.

## UX (simple)

Until ticker exists: read THE_PLAN. Lock Fuel or take a named ticket. No new app.
After ticker exists: open a wallet they already have → see claim units → those units inherit the desk (recirculation, mutual, Affinity +1).
If they need a Dualis app to hold the coin, the architecture failed.

## Desire (philosophy, Dualis side)

People should want this because a real desk got cheaper — hours, watts, 404s — and leftover came home.
Not because a chart went up. Not because a faucet paid them to wait.
Drive desire by closing residual. The coin is the memory of those closes.

## Factory order (real-world compatible)

1. Seated-404 → 0 (still first).
2. Receipt schema + Merkle root publisher (sandbox).
3. Counsel names wrapper + chain.
4. Adapter: PoL receipt → mint call the wrapper cannot skip.
5. Wallet smoke: MetaMask / WalletConnect / one mobile BIP-39 wallet.
6. Only then a Look explainer of how to view a claim — still no Dualis buy button.

A staking widget on a bleeding plate is forbidden.
