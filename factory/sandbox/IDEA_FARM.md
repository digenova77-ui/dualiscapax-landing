# IDEA_FARM

The idea farm is not a pile of notions.
It is FACTORY_TEN running forever.

```
world / desk / chat / Drive
  → measure live plate
  → cue ten (what is weak, not what is pretty)
  → DCLM collapse
  → one atom on the live tree
  → re-curl
  → still-open list is the next seed
```

An idea that cannot survive that loop is not an idea. It is a toy.
Twenty-five new rooms while the teacher door 404s is not a farm. It is debt.

Coin ideas wait behind company doors.
Ads wait behind a 200.
Energy buyouts wait behind a residual ledger that moved.

Never idle: if the ten did not move, work the same ten.
If the ten moved, cue ten again from the new plate.
That is how the farm manifests.
