# UR-1 — Unity Ring Standard (draft)

One seat. One named statute book. Last link is the human.
Not deployed as a product. Not an offering. DualisCapax ≠ coin ≠ government.
Look $0. Phrase never leaves the device.

Goal: any desk (Ice, teacher, SIMA, personal) can implement the same hatch + ring rules.
If a desk cannot name its ring, it must say `awaiting_ring` — not borrow a neighbour's book.

## Objects (normative)

**Seat** — device-local handle after phrase unlock. Not email. Not a Dualis account. Not a wallet.
`UnityID` human form `U1` / public `DC1-…` / hatch children `.01` ice `.02` teacher `.03` sima `.04` visitor `.05` personal.

**Phrase** — eight words, DCVault, PBKDF2+AES-GCM, no reset email. Same words open every door on that device.

**Ring** — `jx` code for the book this seat may *draft* against (ON, CA-xx, US-xx, GB, …).
Unset `jx` ≡ `awaiting_ring`.

**Confirm** — second bit. Phrase ≠ confirm. Classroom, file, wire, trade require confirm.

**Grant** — default OFF. Named other-seat + field bits. `sent=false` until a cited pipe exists.

**Receipt** — hash of work without PII payload. Counts not names.

## MUST

1. One phrase store per device. No second word list for teacher vs Ice vs personal.
2. Hatch a role from that session. Do not mint a fourth identity store.
3. Look / L1 readable at $0 without phrase.
4. Student names, tax slips, trade lots stay in the vault. Never git, never Look, never coin calldata.
5. `jx` set only after confirm, or stay `awaiting_ring`.
6. Agents draft only against the named ring. Other rings are holes.
7. Last link: file / pay / record-class / share-card requires confirm. Agents prepare.
8. Dualis pages do not file CRA, IRS, or a broker order.
9. Coin mint is PoL-1, not a Unity hatch.
10. Home and ice.html are not Unity rewrite targets.

## MUST NOT

- Map all Earth rings in one night and call it finished.
- Use Ontario packs as another country's truth.
- Treat "not posting" as authority to film children.
- Put ticker on a Unity poster.
- Let an agent hold the phrase.
