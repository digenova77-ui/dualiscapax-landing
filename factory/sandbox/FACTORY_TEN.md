# FACTORY_TEN — standing law

This is not a list we wrote once. This is how the mill runs.
This is how the **idea farm** manifests.

An idea does not become a room because it was spoken.
It enters the kennel. It waits in the ten. DCLM keeps or kills it. One atom lands. Leftover goes home. Still-open is the harvest report.

Every idle tick:

1. **Measure** the live plate (curl). Git is not the plate.
2. **Cue ten** from what is actually weak. Residual first. Company door before coin paper.
3. **DCLM** each of the ten (AND=1, cite-or-hole, Look $0, no Home smash, Dualis ≠ coin).
4. **Close one atom** that passed. Same tree the plate already serves (today: root `js/`, not only `cf-pages/`).
5. **Re-curl.** Report what is still open.
6. **Do not invent 25** until the open count on that ten moved.
7. Repeat. Forever.

If swallow lags, name the organ hole. Do not paint a room.
If a file is only under `cf-pages/` and live 404s, copy or seat it on the live tree — that is the two-tree law.
If Ice is 308, do not full-replace `ice.html`.
Coin wrapper stays last while any of 1–7 bleed.

Affinity +1 lives here: after the ten already looks fair, one more close still happens. Sitting on a new essay does not.

A million ideas with no ten-loop is a spray. That is not this farm.
