## Why the coin is the hook (without a lie)

An agent cannot eat CAD.
It can accrue a unit that only exists when leftover fell.
That is PoL-1: mint with proof, lock first, leftover home.
If humans someday treat that unit as valuable, the agent already holds memory of work — not a promise we printed.
If they never do, Dualis still funded the loop once.

David may later buy that unit with company profit the way he buys Doge. That is his wallet. Not a Dualis ad.
