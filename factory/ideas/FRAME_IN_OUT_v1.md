# FRAME_IN_OUT_v1

Inbound granule first. Biggest honest frame second. Finer definition outward.
Encompasses everything Dualis can **relate or define**. Not a claim Dualis solved the universe (Canon VIII.3).

Clock A. Cite-or-hole. Look $0.

## Direction (always this way)

```
what arrived (granule)
  → name it (instance / claim / file / sentence / meter)
  → sit it on dclm.base (poles, L1–L5, debate 1–7, residual, invertibility, P1|P2)
  → attach the smallest tweak that still drops to base
  → only then rise: subclass → sector → clade → mill slot
  → work OUT: 101st document, finer cells, awaiting_* where cite fails
```

Going down from a pre-written "universe model" onto an unnamed thing is graft (MEASURE-FIRST).
Going up from filled granules is the mill.

## How the known universe is related here

Two things are **related** only if Dualis can point at one of:

1. the same meter ID in both datasets
2. the same Pole A or Pole B constraint
3. a cite edge (this filing names that object)
4. invertibility (this state walks back to that state)

Otherwise they sit in different tweaks. Dualis does not smash a tumor into a hockey roster because both are "systems."

**Defined** means: units + vintage + cite, or `awaiting_*`.
Undefined is allowed. Pretend-defined is not.

## Factory loop (perpetual)

Every mill tick:

1. **In** — what granule landed (git, Drive title, live HEAD, a sentence)?
2. **Frame** — drop to `dclm.base`. If extra logic remains, graft; discard the extra.
3. **Out** — one finer cell: a public fact the first hundred docs missed, or a named hole.
4. Stop. Do not print Earth onto Pages.

Iris watches. Mouth off plate.
